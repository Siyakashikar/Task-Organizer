Full-Stack Task Management System

The website is a Full-Stack Task Management System designed to manage tasks efficiently.

1. The server-side is built using Node.js.

2. APIs are written using Express.js for handling CRUD operations and user authentication.

3. The database used is MongoDB to store user and task data.

4. The frontend is developed using HTML, CSS, and Vanilla JavaScript, providing a responsive and interactive user interface.

5. This project demonstrates end-to-end full-stack development, integrating frontend UI with backend APIs and a NoSQL database.
